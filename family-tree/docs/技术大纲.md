# 家谱网站 - 技术大纲

## 一、项目概述

构建一个在线家谱管理平台，支持家族成员录入、家谱树可视化展示、世系图谱浏览、家族资料管理等功能。前端使用 Vue 3，后端使用 Java 微服务架构。

## 四、微服务划分

### 4.1 服务清单

```
family-tree-platform/
├── family-gateway          # API 网关 (端口: 8080)
├── family-common           # 公共模块 (工具类、通用实体、异常处理)
├── family-user             # 用户服务 (端口: 8101)
├── family-tree             # 家谱服务 (端口: 8102)
├── family-member           # 成员服务 (端口: 8103)
├── family-media            # 媒体服务 (端口: 8104)
└── family-notify           # 消息通知服务 (端口: 8105)
```

### 4.2 各服务职责

#### family-user（用户服务）
- 用户注册/登录（手机号 + 验证码、账号密码）
- 用户信息管理
- 权限角色管理（家族管理员、普通成员、访客）
- Token 签发与校验

#### family-tree（家谱服务）
- 家谱创建/编辑/删除
- 家谱基本信息管理（堂号、郡望、家训、家族简介）
- 世系辈分管理
- 家谱分享与权限控制
- 家谱导出（PDF/图片）

#### family-member（成员服务）
- 家族成员 CRUD
- 成员关系维护（父子、夫妻、兄弟）
- 成员详细资料（生卒年月、籍贯、事迹）
- 家谱树数据结构构建与查询
- 成员搜索

#### family-media（媒体服务）
- 头像/照片上传
- 家族老照片管理
- 文件存储管理（对接 MinIO）
- 图片压缩/缩略图生成

#### family-notify（消息通知服务）
- 站内消息通知
- 邀请加入家谱通知
- 系统公告

## 五、数据库设计

### 5.1 核心表结构

```sql
-- 用户表
CREATE TABLE sys_user (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    username        VARCHAR(50) NOT NULL UNIQUE,
    password        VARCHAR(128) NOT NULL,
    nickname        VARCHAR(50),
    phone           VARCHAR(20),
    avatar          VARCHAR(255),
    status          TINYINT DEFAULT 1,
    created_time    DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_time    DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 家谱表
CREATE TABLE family_tree (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    name            VARCHAR(100) NOT NULL COMMENT '家谱名称',
    surname         VARCHAR(20) NOT NULL COMMENT '姓氏',
    hall_name       VARCHAR(50) COMMENT '堂号',
    origin          VARCHAR(100) COMMENT '郡望/发源地',
    motto           TEXT COMMENT '家训',
    description     TEXT COMMENT '家族简介',
    cover_image     VARCHAR(255) COMMENT '封面图',
    creator_id      BIGINT NOT NULL COMMENT '创建者',
    visibility      TINYINT DEFAULT 0 COMMENT '0-私有 1-公开',
    created_time    DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_time    DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 家族成员表
CREATE TABLE family_member (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    tree_id         BIGINT NOT NULL COMMENT '所属家谱',
    name            VARCHAR(50) NOT NULL COMMENT '姓名',
    gender          TINYINT COMMENT '0-女 1-男',
    birth_date      DATE COMMENT '出生日期',
    death_date      DATE COMMENT '去世日期',
    is_alive        TINYINT DEFAULT 1 COMMENT '是否在世',
    generation      INT COMMENT '第几世/辈分序号',
    generation_name VARCHAR(20) COMMENT '字辈',
    birthplace      VARCHAR(100) COMMENT '出生地',
    residence       VARCHAR(100) COMMENT '现居地',
    biography       TEXT COMMENT '生平简介',
    avatar          VARCHAR(255) COMMENT '头像',
    parent_id       BIGINT COMMENT '父亲ID',
    spouse_id       BIGINT COMMENT '配偶ID',
    sort_order      INT DEFAULT 0 COMMENT '排序(长幼)',
    user_id         BIGINT COMMENT '关联系统用户',
    created_time    DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_time    DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_tree_id (tree_id),
    INDEX idx_parent_id (parent_id)
);

-- 家谱成员权限表
CREATE TABLE tree_permission (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    tree_id         BIGINT NOT NULL,
    user_id         BIGINT NOT NULL,
    role            VARCHAR(20) NOT NULL COMMENT 'admin/editor/viewer',
    created_time    DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_tree_user (tree_id, user_id)
);

-- 家族媒体/照片表
CREATE TABLE family_media (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    tree_id         BIGINT NOT NULL,
    member_id       BIGINT COMMENT '关联成员',
    file_name       VARCHAR(255),
    file_url        VARCHAR(500) NOT NULL,
    file_type       VARCHAR(20) COMMENT 'image/video/document',
    description     VARCHAR(500),
    upload_user_id  BIGINT NOT NULL,
    created_time    DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 辈分字辈表
CREATE TABLE generation_rank (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    tree_id         BIGINT NOT NULL,
    rank_order      INT NOT NULL COMMENT '辈分序号',
    rank_char       VARCHAR(10) NOT NULL COMMENT '字辈用字',
    UNIQUE KEY uk_tree_rank (tree_id, rank_order)
);
```

### 6.2 家谱树可视化方案

使用 **D3.js** 实现家谱树渲染，支持以下交互：

- 纵向/横向树状布局切换
- 节点展开/折叠
- 缩放和平移
- 点击节点查看成员详情
- 不同性别节点颜色区分
- 配偶关系横向并列显示
- 支持导出为图片

## 七、核心 API 设计

### 7.1 用户相关

```
POST   /api/user/register          # 注册
POST   /api/user/login             # 登录
GET    /api/user/info              # 获取当前用户信息
PUT    /api/user/info              # 修改用户信息
```

### 7.2 家谱相关

```
POST   /api/tree                   # 创建家谱
GET    /api/tree/list              # 我的家谱列表
GET    /api/tree/{id}              # 家谱详情
PUT    /api/tree/{id}              # 修改家谱信息
DELETE /api/tree/{id}              # 删除家谱
GET    /api/tree/{id}/chart-data   # 获取家谱树渲染数据
POST   /api/tree/{id}/export       # 导出家谱
```

### 7.3 成员相关

```
POST   /api/member                 # 添加成员
GET    /api/member/{id}            # 成员详情
PUT    /api/member/{id}            # 修改成员
DELETE /api/member/{id}            # 删除成员
GET    /api/member/tree/{treeId}   # 获取家谱下所有成员
PUT    /api/member/{id}/bindParent # 绑定父子关系
PUT    /api/member/{id}/bindSpouse # 绑定配偶关系
GET    /api/member/search          # 搜索成员
```

### 7.4 媒体相关

```
POST   /api/media/upload           # 上传文件
GET    /api/media/tree/{treeId}    # 家谱相册列表
DELETE /api/media/{id}             # 删除文件
```

## 十一、关键技术要点

1. **家谱树数据结构**：使用邻接表模型（parent_id）存储，查询时递归构建树结构，配合 Redis 缓存热点家谱数据
2. **D3.js 树渲染**：采用 `d3.tree()` 布局算法，自定义节点模板支持头像/姓名/生卒年展示
3. **微服务通信**：服务间使用 OpenFeign 调用，网关统一鉴权转发
4. **统一响应格式**：`{ code: 200, message: "success", data: {} }` 标准化所有 API 返回
5. **全局异常处理**：`@RestControllerAdvice` 统一捕获异常，避免暴露技术细节
